Collector · Free cloud setup

A free Supabase project stores your private collection. Vercel Hobby hosts the app. Stay on the Free/Hobby plans; no paid market API or custom domain is required.

1. Create your Supabase project

  1. Sign in at Supabase. Create a Free organization and a project named Collector. Choose the nearest region and save the database password privately.
  2. Open SQL Editor and run supabase/004-cloud-workspace.sql from the Collector project folder. This file is standalone; earlier schema files are not required.
  3. In project settings, find the project URL and publishable key (or legacy anon key). Never use the secret/service-role key in the app.
  4. Add these to .env.local in your local project:
    NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR-PUBLISHABLE-KEY
  5. In Authentication → URL Configuration, allow http://127.0.0.1:3000/ as a redirect URL for local migration. Restart Collector.

2. Deploy on Vercel Hobby

  1. Sign in at Vercel. Use Hobby for personal use.
  2. From the project folder, use the official Vercel CLI to link and deploy the Next.js project. Use the standard build command next build and no custom output directory. No Git repository is required for CLI deployment.
  3. Add the same Supabase URL and public key to the Vercel project's Production environment variables, then redeploy.
  4. In Supabase Authentication → URL Configuration, set Site URL to the deployed HTTPS address and add that exact address as an allowed redirect. Keep the local redirect during migration.

3. Move your local collection

  1. On your PC, open the current local Collector at http://127.0.0.1:3000/. Download a backup first.
  2. Choose Account & sync and sign in by email. Open the email link on this PC. Choose “Copy this device’s collection.” Your original local collection stays saved.
  3. Open the hosted address and sign in with the same email. Your cloud collection will load. If two devices edit simultaneously, Collector keeps the pending edits locally and reports a conflict rather than overwriting another device.

4. Use on iPhone

Open the hosted HTTPS address in Safari. Sign in with the same email. Tap Share → Add to Home Screen → Open as Web App. If the installed web app requests sign-in again, use its Account & sync button.

Free-plan limits

Supabase may pause a low-activity free project after a week; resume it in the dashboard. Current photo sync stores compressed images with your collection in the private database. A workspace is limited to 10 MB in this first cloud version; reduce large photos if needed. Download backups regularly. The installed app requires a connection to load after closing; if the app is already open, edits stay locally and retry when you reconnect. Native iPhone widgets and paid market feeds are separate.
